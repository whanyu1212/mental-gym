# Course note template

This is a template, not a study journal. Copy it, then fill in a real module. Leave `kind` as `course` on the copy, and set `courseId` and `moduleId` to IDs from `web/src/data/roadmap.ts`. Do not commit private weekly hours here.

```yaml
kind: course
courseId: stanford-cs229-2022
moduleId: foundation-01-python-and-complexity
relatedExercises:
  - domain: note
    slug: python-dsa-toolkit
sourceUrl: https://cs229.stanford.edu/
```
