# DSA from Scratch — Overview

> Hand-rolled implementations in `src/dsa_from_scratch/python/`

Building data structures from scratch is the best way to deeply understand how they work. Each implementation focuses on correctness and clarity over micro-optimization.

## Implemented

| Category | Structure | Status |
|----------|-----------|--------|
| Sorting | Bubble, Selection, Insertion, Merge, Quick | ✅ |
| Arrays | Dynamic array | ✅ |
| List ADT | Singly linked list, Doubly linked list | ✅ |
| Binary Heap | Min-heap, Max-heap | ✅ |
| Hash Map | Separate chaining hash map | ✅ |
| Trees | BST, AVL tree | ✅ |
| Graphs | Adjacency list graph, BFS, DFS | ✅ |

## Philosophy

Each implementation follows:
1. **Interface first** — define the public API (methods/operations)
2. **Invariants** — document what must always be true
3. **Edge cases** — empty, single element, duplicates
4. **Complexity** — time and space for each operation
